`tracewin_project.ini` is LightWin's `generic_project.ini` (MIT licence, A. Plaçais,
https://github.com/AdrienPlacais/LightWin) — a binary TraceWin options file used as
the project argument for headless runs; every physics setting is overridden on the
command line (`dat_file=`, `energy1=`, `freq1=`, `current1=`, `nbr_part1=`).
